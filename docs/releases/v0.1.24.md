# v0.1.24

本版主题：修掉三处「看着像没反应」的老问题，首回合上下文再瘦一轮。

## 一、修了什么

- **精选技能包能装能卸了**：随包技能包以前把「安装包里有没有技能」当成「你装没装」，所以每台机器都显示「已安装」、界面没有安装按钮，点「更新」也看不出变化。现在按真实状态显示「安装 / 更新 / 卸载」，装完状态立刻正确。
- **压缩后「等待模型回复」不再消失**：上下文压缩完成时偶尔会把运行态行清掉（时序不同表现不同），现在压缩完成不再误清，交给回合自己收尾。
- **更新链三处断点**：
  - 重启应用后仍能看到已经下好的「⬇ 安装」；
  - 安装包被磁盘清理/杀软删掉时，徽标变成「重试」，不再点了没反应；
  - 从应用里点「安装」不再被机器上的旧版全机安装拦住。
- **首回合更省上下文**：内置 MCP 改为按需网关调用、常驻指令精简，首轮占用明显下降。
- **语音播报不再挂住**：播报合成加硬超时。

## 二、mac 适配审计结论

`node scripts/mac-audit.mjs v0.1.23 HEAD`：命中 4 条，逐条判读后**无真缺口** —— 2 条为拓展点说明文案里的 Windows 示例路径，1 条是 JSON 转义正则（跨平台正确写法），1 条为同段重复归类。脚本自带正则自证。

## 三、mac 首次打开自救

1. 在「下载」里解压 zip；2. 拖进「应用程序」；3. 首次打开若提示无法验证，打开终端执行（把应用图标拖进终端自动填路径）：
   `xattr -cr "/Applications/PPcode.app"`；4. 若仍报错 640，右键应用 → 打开一次即可。

引擎 @openai/codex 0.171.0；随包内置工具与运行时依赖无落后项（仅 REA 按既定策略锁版本）。
