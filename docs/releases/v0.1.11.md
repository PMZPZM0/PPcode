# v0.1.11 发版说明

本版主题：**工作伙伴（群聊）全面对齐主对话 + CLI 智能体自动跟随你的模型配置。**

> 版本号说明：本版与桌面版 v0.0.55 同源（PPcode 版本线独立），改动面较大：跨 8 天、300+ 提交。

## 一、修了什么（按用户感知排序）

### 1. 工作伙伴（群聊）与主对话对齐
- 回复改成主对话那种回合视图：逐条实时上屏、过程收进大折叠、轮末出汇总卡；
- 补齐用量页脚、推理浮窗（两种展示）、网页来源条；
- 复用主对话的滚轮与「回到底部」、记录懒加载、思考档位按官方规格联动；
- 输入框 @ 变行内 chip；引用改居中弹窗可多选；伙伴资料卡、@ 候选面板、群内搜索各成独立板块；
- 成员头像可自定义（只作用于本群）。

### 2. 群伙伴直接用本机 CLI 回话
- 群里的 CLI 成员改为本地进程直接回复，不再经引擎转交；
- 修掉一批真实故障：Qwen Code 协议不匹配（405）、Kimi 配置被焊死在旧中转地址、Claude 注入错参数族、stdin 未关闭导致正文丢失；
- 出错时给「下一步怎么做」，不再甩原始 JSON。

### 3. CLI 智能体自动跟随模型配置
- 装好即配、启动 / 切供应商 / 安装后自动同步；
- 模型配置页新增「同步给 CLI」弹窗：每个 CLI 一个定制按键（Claude 与 iFlow 写自己的配置文件并提示密钥明文、需二次确认；Codex / Kimi 重写配置不含密钥；Qwen 等自动注入；Gemini / Comate / OpenClaw / Qoder / QwenPaw 如实标注需自己登录）；
- 写入修正：内容已一致算成功（不再假报失败）、用户配置是坏 JSON 时放弃写入（不覆盖原配置）、首次改动留 `.harness.bak`。

### 4. 远控与更新
- 手机看屏（只读）+ 桌面可见提示与停止键；远控 RPC 白名单 + 运行中排队（入队 / 立即 / 撤回）；
- 组件更新加官方源兜底（滞后镜像不再挡住官方源），19 个运行时依赖升到最新。

## 二、mac 适配审计结论

审计 `node scripts/mac-audit.mjs v0.1.10 HEAD`：命中 115 条，逐条判读后本版新增逻辑无真缺口（平台门控 / 守卫夹具 / 页面文案）。CLI 相关两处命中为误报：`04-cli.ts` 的 `win32` 三元门控分支完整；`cli-command.mjs` 的正则 `\s` 被路径模式误判。

## 三、mac 首次打开自救（带路径）

1. 在「下载」里双击解压；2. 把 App 拖进「应用程序」；3. 把图标拖进「终端」窗口让它自动填出路径；4. 在路径前加 `xattr -dr com.apple.quarantine ` 回车；5. 报错误 640 时改用系统「归档实用工具」重新解压。
