# v0.1.9 发版说明

本版为**维护版**：与桌面版 v0.0.53 同批对齐，内容集中在媒体播放体验与校验门禁。

## 一、修了什么

### 1. 播放速度不再用系统原生下拉
媒体预览的倍速选择（视频条 / 音频条各一处）原来用浏览器原生 `<select>`，下拉弹层无法跟随主题，暗色下是一块白底。改用应用内 `AppSelect`，与其它下拉一致。

### 2. OpenFilm 卡片补回「卸载只做引导」说明
上一轮重构卡片布局时，这句用户可见文案被挪进了代码注释，界面上消失了（守卫【23】钉住的是**可见文案**）。已补回：卸载只会告诉你去系统里怎么删，不会替你删系统目录。

### 3. 门禁判据与实现对齐（不影响功能，但影响发版可信度）
- 播放条宽度判据改为锚定「基础规则」，不再误命中遮罩期的 `display:none` 规则；
- favorites 域拆分后产物路径变更，断言改为多候选探测；
- `applyWindowChrome` 签名早已多出 `bg` 参数，判据同步放宽；
- bag-types 与实现对齐（`install/uninstall` 返回 `boolean`）。

## 二、mac 适配审计

本批改动仅在渲染层与守卫脚本内，**无新增平台敏感代码**（无路径拼接、无 shell 调用、无平台分支）。

## 三、mac 首次打开（与上一版相同）

下载 `.zip` → 解压 → 拖进「应用程序」→ 终端执行 `xattr -dr com.apple.quarantine `（末尾留空格，把应用图标拖进终端自动补路径）→ 回车后双击打开。

## 四、已知问题

- 影视播放仅支持公网片源（已拦截内网/回环地址）；
- 影视源接口清单在界面侧是静态副本，源变更需同步后端配置。
