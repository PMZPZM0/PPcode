# PPcode v0.1.0 发版说明

> **首个正式版。** PPcode 自原版 v0.0.35 的代码基线分出，独立版本序列：本版包含
> 分出以来全部 24 个提交（194 个文件、约 9000 行新增）。版本号从 0.0.x 跳到 0.1.0
> 表示「产品形态成型」，不是破坏性升级——数据目录独立为 `%APPDATA%\PPcode`
> （macOS：`~/Library/Application Support/PPcode/`），与其它安装互不干扰。

## 本版主题：PPtoken 中转站账户一键接入 + 语音播报全链路 + 私有更新通道

---

## 一、中转站账户体系（本版核心）

### 1. 注册 / 登录

- 登录页只有一个入口：**PPtoken 中转站账户**。支持邮箱验证码注册。
- 邀请归因**静默**携带（界面上不出现任何邀请码/邀请链接），注册请求自动带上。
- 凭据净化：全角字符、零宽字符、首尾空白会在提交前自动规整——
  「密码明明对的却报 invalid email or password」这类问题大多出在这里。
  净化失败时给出具体的字段提示；本机已有登录状态时可一键继续。

### 2. 密钥自动配置（新手零门槛）

登录后一键配置模型，自动建密钥并按**候选链**依次尝试：

1. **已生效的套餐分组**（按日 / 周 / 月三个额度窗口判断有效性，快到期的排后）；
2. **余额分组**（`subscription_type=standard`，按倍率从低到高，最多取 3 个）；
3. 以上全不可用时给出**完整的失败原因**，不再被吞掉。

> 背景：pptoken 站点对「无分组密钥」是硬拒（403 `API Key is not assigned to any group`），
> 所以「余额」必须绑到余额分组，不能裸建。

### 3. 密钥管理

- 中转站账户页可查看全部已建密钥；
- 支持**删除**（两段式确认）与**切换分组**；
- 三级弹窗（列表 → 密钥管理 → 确认/表单）全部 portal 到 body，不再嵌在设置页里被裁切。

### 4. 检查更新支持私有仓库

- 发布仓是私有仓库，匿名「检查更新」必然 404。两条出路（详见 `docs/UPDATE-SOURCE.md`）：
  - **方案 A**：在应用内「检查更新」里填 GitHub 只读令牌（Fine-grained，仅 Contents: Read）；
  - **方案 B**：填自定义清单地址 `manifestUrl`（对外分发用，令牌不下发）。
- 私有仓 404 会明确区分「未授权」与「确实没有新版本」，不再静默显示「已是最新」。

## 二、语音播报（与原版同步的全套改动）

- **一个总开关**控制全部播报，状态由宿主下发到引擎指令；
- **播报内容由 Codex 自己写**：运行中念的是「本轮重点」的播报稿，不再复读全文；
- **自动播报两条硬规则**：单轮工具调用超过 10 次、或同一问题返工 ≥2 次时，强制念正文；
- 新工具 `voice_speak_reply`：每段内容是否出声由 Codex 逐条决定；
- **通话避让**：实时语音通话期间独立播报静音，避免两个声音叠在一起（已钉成守卫）。

## 三、其它新功能

- **对话流「轮询」板块**：后台轮询任务独立成卡片展示，输入框左上角有后台任务胶囊入口；
- **全新品牌**：桌面 / 任务栏 / 托盘图标三处同源换新 logo（SVG 母版同一管线渲染），
  品牌文字为流动渐变（`:root --brand-ink` 单一渐变源），去掉了 "Desktop" 副行；
- **桌面启动器** `PPcode.cmd`（清理 `ELECTRON_RUN_AS_NODE` 环境变量后启动）。

## 四、修复清单

| 问题 | 根因 | 修法 |
| --- | --- | --- |
| 宠物拖不动 | 穿透翻转判定在渲染层，鼠标事件被穿透窗吞掉 | 改由主进程光标轮询判定穿透翻转 |
| 透明罩挡桌面、软件外面点不了 | 宠物透明窗默认没开鼠标穿透 | 透明窗默认穿透，判定在主进程 |
| 登录报 invalid email or password | 全角字符 / 尾随空白混进凭据 | 提交前净化 + 字段级提示 |
| 建密钥表单渲染两份 | 组件里同一表单写了两遍 | 判据钉死计数 === 1 |
| 弹层被设置页裁切 / 内嵌难看 | 祖先 `transform` 把 `position:fixed` 劫持成相对容器 | 统一 portal 到 body |
| 同一段语音连播两次 | 同回合去重缺实现 | 句子级去重（实现与判据同轮补齐） |

## 六、macOS 首次打开（安装包未签名，Gatekeeper 会拦）

1. 把下载的 zip 解压，把 **PPcode.app** 拖进「应用程序」；
2. **右键**点 PPcode.app → 选「打开」（不要双击）；如仍被拦，
3. 打开「终端」，输入 `xattr -cr `（注意后面有个空格），**把 App 图标从「应用程序」拖进终端**
   （路径会自动填上，不用手敲），回车。完整命令形如：
   `xattr -cr "/Applications/PPcode.app"`；
4. 若启动报错且错误码含 **640**：那是 Gatekeeper 隔离属性没清干净，重做第 3 步即可。

Apple 芯片（M 系列）请下 `PPcode-0.1.0-arm64-mac.zip`，Intel 请下 `PPcode-0.1.0-x64-mac.zip`。

## 九、已知问题

- 安装包未签名（Windows SmartScreen / macOS Gatekeeper 都会提示），按第六节步骤放行；
- 令牌方案只适合自用少量机器；**对外分发必须走自定义清单**（不要把令牌打进安装包）；
- 上游不允许「解绑分组」：改分组是覆盖式更新，删除重建即可达到解绑效果。
