# v0.1.10 发版说明

本版主题：修「Git 自动安装失败」，压缩完成后并入回合过程列表。

## 一、修了什么

1. **Git 自动安装失败（四条下载通道全挂）**
   - 现象：开发工具页装 Git 时四条通道全部失败，报 `curl: option --retry-all-errors: is unknown`。
   - 根因：**不是网络**。该参数 curl 7.71.0（2020-07）才加入；Windows 自带系统 curl 常年停在
     7.55~7.6x，参数解析阶段直接退出。"文件大小 37.2 MB"能取到恰是反证——大小探测不带该参数。
   - 修法：先探测 curl 版本，≥ 7.71 才使用该参数。

2. **上下文压缩完成后进回合过程列表**
   - 压缩完成后进到回合的过程列表里（和已深度思考 / 请求接口排在一起，跟着折叠收起）；
     压缩运行中仍可随时点停止。
   - 连带修复：用户点「停止」后压缩线不再消失；压缩失败不会再显示成"正在压缩"。

3. **长会话往上滚被弹回**：上翻历史时不再被历史水合的下滑判据自动拉回底部。

4. **子会话对齐与复用**：侧栏子会话缩进与父行标题列对齐；向同一目标重复派活时复用已有子会话。

5. **QQ 机器人连不上**：取令牌接口 404，统一改走正确接口。

## 二、mac 适配审计结论

`mac-audit.mjs v0.1.9..HEAD`：命中 **23 条**（exe 3 / win32 5 / darwin 1 / backslash 12 /
winpath 2 / powershell 0 / appdata 0），逐条判读：守卫断言夹具（含 win32/darwin 对照组）、
双兼容路径写法（`split(/[\\/])/`）、Windows 专用安装器内部路径与注释文案——
**逐条判读后无真缺口**。

## 三、mac 首次打开自救（带路径）

下载的是 `.zip`，macOS 默认会拦一下。按顺序做：

1. 在「下载」里双击解压，得到 `PPcode.app`；
2. 把它拖进「应用程序」文件夹；
3. 打开「终端」，输入 `xattr -dr com.apple.quarantine ` （**末尾留一个空格**），
   然后把**应用图标直接拖进终端窗口**——路径会自动填好，不用自己找；
4. 回车，再回到「应用程序」双击打开。

若提示 **错误 640**（"没能打开，因为 Apple 无法验证"），重复第 3 步，确认拖入的是「应用程序」里那个图标。
