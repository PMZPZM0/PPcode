# v0.1.2 发版说明

> ⚠️ **v0.1.1 撤回**（那版 CI 未跑完，从未对外发布）。本版重新打包，带覆盖安装修复。

本版主题：覆盖安装不再卡死 + 检查更新走国内镜像 + 上游 10-11 能力同步。

## 一、修了什么

1. **覆盖安装卡「无法关闭」（本版主修）**
   - 现象：运行中覆盖安装 → 安装器弹「PPcode 无法关闭，请手动关闭它」，重启电脑仍复现。
   - 根因：electron-builder 的运行中检查只发 `WM_CLOSE`，而本应用「关闭窗口 = 最小化到托盘」把消息吞了；应用若以管理员权限运行，安装器的 kill 还会被判定为「高权限进程」失败。
   - 修法：`build/installer.nsh` 用 **`preInit` 宏**（模板里最早的钩子，早于运行中检查执行）按进程名 `taskkill /F /T` 强杀整棵进程树。
   - 若应用以管理员权限运行，请右键安装器「以管理员身份运行」。

2. **检查更新与下载走国内镜像**：`gh-proxy → ghfast → 直连` 三档依次尝试；安装包按 GitHub 资产 digest 校验 sha256。

3. **同步上游 10-11 能力**：本地 HTML/CSS → MP4、图像工坊与免费模型网关、输入框底栏动态状态灯、委派链路。

## 二、mac 适配审计结论

`scripts/mac-audit.mjs v0.1.0..HEAD`：正则自证通过；命中 15 条，逐条判读均为断言夹具、平台门控内文案或跨平台安全的路径切分；**winpath 0 条、appdata 0 条** ⇒ 无真缺口。本版安装器修复为 NSIS（Windows 专用），mac 打包链路零改动。

## 三、mac 首次打开自救（带路径）

1. 在「下载」里解压 zip；
2. 把 **Codex Harness.app** 拖进「应用程序」；
3. 首次打开若提示无法验证开发者：打开「终端」，输入 `xattr -cr `（末尾有空格），**把 app 图标拖进终端自动填全路径**，回车后再双击打开；
4. 若提示已损坏（错误码 640）：同样是上面的 `xattr -cr <路径>` 命令，执行一次即可；
5. 仍打不开时：系统设置 → 隐私与安全性 → 仍要打开。
