# v0.1.6 发版说明

本版主题：**指挥中枢（原 BOSS 会话）从「能派活」走到「能自己拉人、验收、出成品」——并把
输入框底栏、浮层、通知这三处长期被挤没/裁切/点了没反应的问题一次改完。**

> 版本号说明：0.1.6 自 0.1.5（10-23）起累积 265 个提交，其中 91 个 feat、84 个 fix。
> 主要内容来自与主仓（Codex Harness Desktop）的同步，另有本仓品牌面（PPtoken 中转站口径）
> 的相关收口。上版 0.1.5（10-23）→ 本版 0.1.6（10-26）。

## 一、改了什么（按用户感知排序）

### 1. 指挥中枢：自己拉人、自己派活、自己验收
- **改名**：原来叫「BOSS 会话」，现在整套文案统一叫**指挥中枢**（侧栏、欢迎页、帮助、快捷键清单）。
- **它就是一个普通会话**：之前那套「群聊专属界面」整块删除 —— 点进去是正常时间线、正常输入框、
  正常消息渲染。群的信息（成员、任务、汇报）叠在这个会话上，而不是替代它。
- **拉人**：拉人面板改成**专家成员列表**，中枢右侧常驻一列**成员轨**（头像 + 状态环）；
  成员进出、谁在忙一眼看见。成员轨末位是**办公室预览**入口。
- **投递机制重做**：群事件不再一律塞进引擎的用户消息队列 —— 中枢有回合在跑就直接追加进当前回合
  （立刻送达、不进队列、不产生 pending turn），空闲才进队列。原来「一卡就堆几十条、界面炸开」
  的根因就是这个。

### 2. 成员交活：成品落盘 + 文件卡 + 汇报挪到回复下方
- 成员交活时把正文**落盘成文件**（`群交付/<任务号>-<标题>.md`），中枢会话里出**文件卡**，点开即预览。
- 群汇报从回合卡**上方**移到**整张卡之后**：先看它的回答，再看成员汇报，不再一进来先撞一屏汇报。
- 纯系统提示（成员进出、失败、超时）改成**紧凑灰行**，不再套一层「群汇报」空卡。
  历史会话里那些「预算已用 80%」的刷屏提示也不再渲染（同一个会话从 41 张空卡降到 6 张）。

### 3. 语音：悬浮球换新脸 + 合成引擎三选一
- 悬浮球改成 **Grok Bot 胶囊眼圆脸**，6 套外观可切换，**眼神跟着鼠标走**（瞳孔随速度缩放），
  打字时弹一盏**迷你键盘**。
- 语音合成引擎改成三张卡片：**Kokoro 真接通、按需下载**，不再只有单一引擎。

### 4. 输入框、浮层与通知：不再挤没、不再裁切、点了有反应
- **底栏按「有位置就缩成图标、没位置才隐藏」重排**：原来 760px 起把附件按钮和整块模型控件
  `display:none`、640px 起连胶囊图标一起藏 ⇒ 「缩成图标」变成「缩成空气」。
- **左侧组不再抢光宽度**：`flex: 1 1 auto` 会增长吃满，把右侧整组（上下文环 / 模型 / 强度 /
  麦克风 / 发送）压到 0 —— 越窄越明显。改成按内容排，右组恒定可见（实测 320px 仍完整）。
- **浮层按内容自适应**：引用文件子菜单固定 250px、上下文容量浮层固定 268px —— 长的被硬切
  （底部还留半行残片）、短的留一大片空白。改成 `max-content` + 上限；菜单副标题补单行省略。
- **浮层不再被裁**：去掉三处会裁掉子级绝对定位弹层的 `overflow: hidden`（点胶囊/上下文环
  什么都不显示的根因）。
- **点通知能唤出应用**：更新完成通知原来**连 click 都没接**；应用内通知只 `show()+focus()`，
  窗口最小化时不还原。两处都改成 `isDestroyed → isMinimized&&restore → show → focus`。

### 5. 侧栏与快捷区
- **新建任务 / 指挥中枢 / 搜索任务** 改为上下三行整行宽；**拓展功能**（技能 / 插件 / MCP）
  独立成常驻一行，不再藏在「更多」里。
- **功能入口改为右侧浮层**：支持拖动排序、侧栏/对话框上方两种位置、溢出收进「更多」。
- 会话行改**单行紧凑布局**；侧栏快捷键默认隐藏、悬停才显示。

### 6. 文件预览
- 文件卡点开出**灯箱预览**（可编辑、可拖动），右栏预览可拖动、能向上拉满。

### 7. 账号与中转站（本仓品牌面）
- 中转站页文案统一到 **pptoken** 口径（页头 / 添加卡 / 横幅 / 弹窗注释 / 占位符）。
- 登录弹窗站点**钉死 pptoken**，删除可编辑的站点地址字段；注册默认走云管理。
- **PPtoken 卡与云端模型卡置顶**：之后新增的供应商卡都排在它们下面。
- 数据管理页、设置页统一成简洁白卡版式（分组小标题 + 单张白卡 + 行分隔线）。

## 二、验证方式

- `npm run build` ✓；`npm run lint` ✓
- 守卫 11r（新功能介绍）**25/25**；守卫 22（群编排）通过
- 真机实测：输入框三档（480 / 380 / 320）底栏右侧组全部可见、右侧超出 0px；
  弹层用 `elementFromPoint` 命中检测（中心点命中自身 = 未被子级裁切）

## 三、已知事项

- 0.1.5 → 0.1.6 为**跨较大跨度升级**，首次启动会弹一次「新功能介绍」，看完不再弹。
- 通知点击需要有 AUMID 的正式安装包才生效（未打包运行 `electron.exe` 时 Windows 不派发点击）。
- 群交付文件落在**群工作区**（有则优先）或 `%APPDATA%\PPcode\boss-groups\outputs`。
