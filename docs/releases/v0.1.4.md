# v0.1.4 发版说明

本版主题：**反馈与官网入口换到更快的域名。**

## 一、改了什么

反馈页与官网地址从 `www.jvszzp.ltd` 迁到 **`dl.ppz123.asia`**。

替换位置：

- `.github/ISSUE_TEMPLATE/` 三个模板的反馈页链接、`config.yml` 的官网地址
- 更新检查的 base 常量
- 账号菜单「问题反馈」的跳转地址

### 为什么换

`jvszzp.ltd` 走 **Cloudflare Tunnel**，实测首字节 3.15s、总计 5.25s；且源站用 **Cloudflare Origin Certificate**，改成灰云直连会被浏览器判「证书不受信任」——这是它「关掉就访问不了」的根因。

`dl.ppz123.asia` 是 A 记录直连 `124.220.63.4` + Let's Encrypt 证书，实测 **0.21~0.49s**，快 **10~25 倍**。

## 二、mac 适配审计结论

本版只改字符串常量（域名），不新增平台相关代码（无路径拼接 / 无可执行文件调用 / 无环境变量读取）。

**结论：无真缺口。**

## 三、mac 首次打开

未做 Apple 公证，首次打开会被 Gatekeeper 拦。打开「终端」，把应用图标拖进去（自动补全路径），在路径前加 `xattr -cr ` 回车：

```bash
xattr -cr "/Applications/PPcode.app"
```

只需一次，升级后不用重复。

## 四、已知问题

- `www.jvszzp.ltd` 仍可用但慢，旧书签里的链接不会自动更新。
- 历史发版说明里的旧域名保留原文（是对当时状态的记录）。
