# v0.1.5 发版说明

本版主题：**首启就能用云账号登录（直连客户自建服务器）；浏览器自动化换 Ego Lite，长会话滚动重做。**

> 版本号说明：0.1.5 自 0.1.4 起累积了较长时间的功能批（含与主仓同步的多项改造），
> 反馈页/官网域名迁移也并入本版，不是"只改了域名"的小版本。

## 一、改了什么（按用户感知排序）

### 1. 云账号：首启登录页 + 直连客户服务器
- 首次启动的登录页新增**云管理账号登录**（与网页端同一套账号）：登录后**模型 / 知识库 / 记忆一次配齐**，每一步都有回执。
- 云账号默认服务地址改为**客户自建服务器**（`https://ppcode.pptoken.cc/cloud-api`），不再是公共主站。
- 设置里的「云账户」**不再暴露服务地址输入框**，默认就走上面那个地址；换服务器仍可用环境变量或重登（只是不给普通用户入口）。

### 2. 界面身份统一为 PPcode
- 应用内不再自称 Codex Harness：自我介绍、模型系统提示里的产品名统一成 **PPcode**，避免「装的 PPcode、被叫成别家」。

### 3. 浏览器自动化换成 Ego Lite
- 接入 Ego Lite，移除 Playwright / CloakBrowser 两条旧通道；**每个会话独立 Space**（互不串号）。
- 官方技能包同步进技能目录；检查更新与更新入口收口到控制台。
- Ego Lite 不随包内置（611MB），首次使用给一键安装指引。

### 4. 与主仓同步的功能批（0.0.47 同源）
- **长会话滚动重做**：滚动条按真实回合总数撑开、按页水合、切回旧会话停在原阅读位置。
- **语音播报**：回合头 📢 会话级开关；长播报音质与断句修复；所有窗口最小化时严格静音。
- **文件卡与右栏**：本轮产物文件卡 + 右栏联动预览，创建后又删除的文件也留记录。
- **侧栏与细节**：入口移到底部、统一 4 字命名、新增「登录管理」；实时编辑行收紧为
  `文件名 · 目录 · +N -N`；单实例防重入；任务清单不再重复显示。
- **办公室与宠物**：白色 3D 工位板 + 6 工位分页；黑猫 3D 渲染；气泡贴身、拖动不穿透。

### 5. 模型线路
- PPtoken 默认 API 改为**大陆线路** `cn.pptoken.cc`（国外线路偶发握手失败）。

### 6. 反馈与官网换域名
- 反馈页与官网从 `www.jvszzp.ltd` 迁到 **`dl.ppz123.asia`**：前者走 Cloudflare Tunnel（首字节 3.15s、
  总计 5.25s），后者 A 记录直连 + Let's Encrypt（实测 0.21~0.49s，快 10~25 倍）。
- 三个 Issue 模板、`config.yml`、更新检查 base、账号菜单「问题反馈」跳转同步替换。

## 二、mac 适配审计结论

`node scripts/mac-audit.mjs v0.1.4 HEAD`：**命中 110 条，逐条判读后 1 处真缺口，已修。**

**真缺口（已修）**：`electron/features/free-gateway-ipc.ts` 解压免费网关写死 `7za.exe`；
darwin 随包的是 7-Zip 官方 **`7zz`**（`install-runtimes.cjs` 的 sevenzip marker 就是它）⇒
mac 上「安装免费网关」必失败。现按平台取名（win `7za.exe` / 其它 `7zz`），参数沿用 `x -o<dir> -y`。

**判读为无害**：
- **MoeKoe 音乐客户端**（`exe` / `winpath` / `appdata` 命中）：`moekoe.ts` 已有完整
  `darwin` / `linux` / win 三分支 —— mac 走 `/Applications` + `Contents/MacOS`，安装用 `ditto` 解 zip，
  下载按 `platform × arch` 选 dmg；命中的 `Program Files` / `LOCALAPPDATA` 全在 win 分支内。
- `toolchain.ts` 的 `C:\Program Files`、`%USERPROFILE%` 都在 `platform === "win32"` 分支；
  darwin 的 PATH 单独一套（含 `sevenzip`，所以 `7zz` 找得到）。
- `dev-runtimes` 的 `python.exe + DLLs\_tkinter.pyd` 在 `IS_MAC` 的 **else** 分支（mac 判 `bin/python3` + pip 模块）。
- `ctrl-key` 6 条是 `ctrlKey || metaKey` 与断言夹具；`backslash` 41 条集中在验收脚本与 `replace(/\\/g,"/")` 归一。

## 三、mac 首次打开自救（带路径）

未做 Apple 公证，首次打开会被 Gatekeeper 拦。打开「终端」，**把应用图标拖进终端窗口**（自动补全路径），
在路径前加 `xattr -cr ` 回车：

```bash
xattr -cr "/Applications/PPcode.app"
```

只需一次，升级后不用重复。若提示 **错误 640**（"Finder 无法完成操作"），是同样的 quarantine 属性，
执行上面的命令后重开即可。

## 四、已知问题

- mac 未签名公证；Intel 与 Apple 芯片是两个包（非 universal）。
- 云账号默认地址只指向客户自建服务器。**若这台机器以前登录过别的地址**，账号库里仍记着旧地址
  （这是排障用的设计，不自动改写）——想切回默认：退出登录后重新登录，或在云账户里删掉该账号再登一次。
- 免费网关的 mac 解压修复只做了平台分支复核，**没有 mac 真机回归**（构建机外无 mac 环境）。
