# PPcode v0.1.17 发版说明

本版主题：**补丁更新重建差分基线**，并同步主仓 0.0.62 的群聊与媒体预览改进。

## 一、更新通道（重要）

- 本版起，更新统一交给 electron-updater 下载并安装：**本版仍是完整包**，安装时会登记差分基线。
- **下一版起**才会只下载变化的块（预期几十兆），安装也改为静默 + 装完自启。
- 若手动装 exe 绕过应用内更新，基线会再次缺失，需要再走一次完整包。

## 二、同步主仓的改进

- 群聊只按 @ 说话：成员只有被 @ 时才回；没人 @ 时宿主不再自动把话头交给别人。
- 管理员在一条消息里 @ 多人 ⇒ 按书写顺序逐个执行，前一位交回再叫下一位。
- 媒体预览：视频/图片统一 112×112 正方形缩略图，首屏 4 个可展开收起；音频改为 168×48 长条同一排。

## 三、门禁

- `npm run build` ✓
- `npm run check` 预检通过（棘轮按实测记账）
