# PPcode v0.1.18 发版说明

本版主题：**更新体验收口**（进度条 / 安装遮罩 / 每用户静默安装 / mac 原生通知），外加音色与自媒体工作台修复。

## 一、更新通道按平台分口径

| 平台 | 方式 |
|---|---|
| Windows（NSIS） | **差分补丁**：`exe + exe.blockmap + latest.yml` 三件同发；无基线时下整包并登记基线 |
| macOS（zip） | **完整包**：系统层面没有 NSIS blockmap，每次都是整包；更新完成弹原生通知提示拖进「应用程序」 |

⛔ mac 段不承诺“几十兆补丁”。

## 二、本版改动

- 下载进度条、安装遮罩；安装期间另开小窗提示「正在安装，别重复启动」；
- 默认手动安装（不再自己重启），安装失败不再连环重试；
- 改为当前用户静默安装（oneClick），从旧的全机安装升级会自动迁移；
- macOS 更新完成弹原生通知；
- 音色：下拉恢复「本机音色」；试听走真实合成链；音色名取模型说话人；同一时刻只允许一个合成引擎；
- 自媒体工作台：顶部工具条（版本 / 检查更新 / 更新到 x.y.z / 重载），更新只落 userData，更新后 iframe 自动铺满；
- 细节：产出文件卡补「用 X 打开」入口；音频芯片不再被裁切。

## 三、门禁

- `npm run build` ✓
- `npm run check` 预检通过（棘轮按实测记账）
