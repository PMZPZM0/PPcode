# PPcode

> AI 工作台 · Windows / mac 双平台 · 应用内免登录检查更新

PPcode 是一款让 AI「真正干活」的桌面工作台：对话即调度 —— 任务可以派给专家、专家团与子智能体并行执行，长任务转后台跑完会自动把结果回报回来，对话不断线。

## ✨ 功能

### 🤖 多智能体调度
- **专家 / 专家团 / 子智能体**：把任务派给多个角色并行干活；头像轨与「办公室」像素小屋实时呈现谁在忙什么
- **长任务不断线**：耗时超过同步等待上限的任务自动转入后台继续执行，完成后结果自动回报给发起会话接着推进
- **被调度的会话也是完整成员**：能查项目知识库、读写自己的记忆、调用宿主能力（按角色权限受控）

### 🖼 图像工坊
- AI 生图 / 修图 / 元信息 / 预览四件套，生成即在应用内预览

### ⏰ 自动化
- 定时任务：支持 RRULE 周期与一次性计划，完成后可推送到微信
- 浏览器 / 桌面自动化：RPA 配方保存复用，一键重放
- Windows 控件级操作（UIA 无障碍树）与 mac 辅助功能

### 🧠 记忆与知识库
- 项目知识库：本地文档检索，对中文查询友好
- 分层记忆金字塔：用户 / 项目 / 经验 / 每日日志，容量可按倍率扩展

### 🎙 更多
- 实时语音通话 / 语音播报
- 视频生成 / 3D 模型预览 / 壁纸工坊
- 渠道机器人（微信 / Telegram 里直接对话）
- 技能市场 / 连接器 / MCP

## 📥 下载

到 [**Releases**](https://github.com/PMZPZM0/PPcode/releases/latest) 下载最新版本：

| 平台 | 文件 |
|---|---|
| Windows x64 | `PPcode-<版本>-win-x64.exe` |
| macOS（Apple 芯片） | `PPcode-<版本>-arm64-mac.zip` |
| macOS（Intel） | `PPcode-<版本>-x64-mac.zip` |

应用内置**检查更新**（账号菜单 → 检查更新），无需登录 GitHub；检查与下载均走国内镜像线路。

## 🔓 关于源码

源码与构建流程都在**本仓**（10-12 起由原私有仓 `ppcode-src` 合并进来，一个仓同时是源码与发布页）：

- 自行构建：`npm ci && npm run build`，三端打包见 `.github/workflows/`；
- 发版：打 `v*` tag 触发 CI，三端构建后**直接上传到本仓 Release**（不再跨仓发布）；
- 欢迎 issue 与 PR。
