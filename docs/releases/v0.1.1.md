# v0.1.1 发版说明

本版主题：本地 HTML/CSS → MP4 + 输入框底栏动态状态灯（同步自上游 10-11 批次）。

## 一、修了什么

1. **本地 HTML/CSS → MP4（新功能）**：把网页动画导出成 MP4 视频，零 ffmpeg 依赖，模型可以直接调用。
2. **输入框底栏动态状态灯**：最多亮一盏、多了轮流展示、窄窗口自适应隐藏。
3. **卸载联动与能力边界**：免费模型网关的卸载反向补全、正向反向全链路检查、消息持久化限制说明补齐。

## 二、mac 适配审计结论

`scripts/mac-audit.mjs v0.1.0..HEAD`：正则自证通过；命中 15 条（exe/win32/darwin/backslash/powershell），逐条判读均为断言夹具、平台门控内文案或跨平台安全的 `/[\\/]/` 切分；**winpath 0 条、appdata 0 条** ⇒ 无真缺口。

## 三、mac 首次打开自救（带路径）

1. 在「下载」里解压 zip；
2. 把 **Codex Harness.app** 拖进「应用程序」；
3. 首次打开若提示无法验证开发者：打开「终端」，输入 `xattr -cr `（注意末尾有空格），**把 app 图标拖进终端自动填全路径**，回车后再双击打开；
4. 若提示已损坏（错误码 640）：同样是上面的 `xattr -cr <路径>` 命令，执行一次即可；
5. 仍打不开时：系统设置 → 隐私与安全性 → 仍要打开。
