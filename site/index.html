Capabilities

五件事，
是同时发生的。

下面每一条都对应界面里的实际行为，不是营销词。它们共享同一套内核、同一份记忆、同一组权限——所以你派出去的每个角色，都知道自己该做什么、能碰什么。

01

多智能体调度

Orchestration

把一件事拆给多个角色并行干，而不是排队等一个模型逐句回你。

  • 专家 / 专家团 / 子智能体三层分工，头像轨与「办公室」实时呈现谁在忙什么
  • 长任务不断线：超过同步等待上限自动转后台，完成时把结果回报给发起会话
  • 被调度的会话也是完整成员：能查项目知识库、读写自己的记忆、按角色权限调用宿主能力
02

图像工坊

Image Lab

生图、修图、元信息、预览四件套合在一处，生成完直接在应用里看结果。

  • 改形用编辑，改意用生成——两条路径分开，不互相覆盖
  • 元信息可读可写，方便批量整理素材
03

自动化

Automation

让机器按你的节奏跑，而不是你盯着它跑。

  • 定时任务：RRULE 周期与一次性计划，完成后可推送到微信
  • RPA 配方：浏览器 / 桌面操作录制保存，一键重放
  • 控件级操作：Windows UIA 无障碍树与 macOS 辅助功能
04

记忆与知识库

Memory

长期项目最怕的"上次说到哪了"，这里用分层记忆解决。

  • 项目知识库：本地文档检索，对中文查询做了专门分词
  • 记忆金字塔：用户 / 项目 / 经验 / 每日日志四层，容量按倍率扩展
05

更多入口

Extras

需要时在，不需要时不占地方。

  • 实时语音通话 / 语音播报 · 视频生成 / 3D 模型预览 / 壁纸工坊
  • 渠道机器人（微信 / Telegram 里直接对话）· 技能市场 / 连接器 / MCP
